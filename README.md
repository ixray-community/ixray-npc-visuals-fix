# NPC Visuals fix (ver. 1.0) for IX-Ray Platform

## Overview

This add-on fixes tessellation bugs in the original NPC models and corrects the geometry of joints and exoskeleton components. In the original engine, when the tessellation setting is enabled, the geometry of certain model parts (specifically, oxygen tanks) is interpolated incorrectly, causing them to appear visually "bloated" or "warped". This add-on corrects the meshes and smoothing settings (normals/smoothing groups), restoring the models to their correct shape

## Requirements

Installation:

1. Install original Stalker Call of Pripyat 1.6.02
2. Install current version of IX-Ray (minimum 1.0)
3. Extract addon archive into the game folder
4. Start the game and play

Link to the current __IX-Ray__ [release](https://github.com/ixray-team/ixray-1.6-stcop/releases/latest)

## Обзор

Аддон исправляет баги тесселяции на оригинальных моделях НПС, а также исправляет геометрию суставов и элементов экзоскелетов. В оригинальном движке при включенном параметре тесселяции геометрия некоторых частей моделей (в частности, кислородные баллоны) некорректно интерполируется, из-за чего они визуально "раздуваются" или "плывут". Аддон правит сетки и настройки сглаживания (normals/smoothing groups), возвращая моделям правильную форму
